# テニスコート空き通知（都立浮間公園・北区・板橋区）

次の3つの予約サイトを1時間ごとに確認し、条件に合う空き枠が新しく出たら Gmail でメールを送ります。

| サイト | 確認する施設 |
|---|---|
| 都立公園 | 浮間公園 テニス（人工芝） |
| 北区 | 中央公園・桐ケ丘体育館・滝野川体育館・新河岸川・浮間舟渡の各庭球場 |
| 板橋区 | 硬式テニスの全庭球場（加賀庭球場は除く） |

- 確認時刻：毎日 8:45〜22:15（日本時間）の1時間半ごと（1日10回）
- 通知条件：土日・祝日の全時間帯、または開始が18時以降の枠
- メール本文：
  - **新しい空き**：場所・日付・時間
  - **以前通知済みで、まだ空いている枠**：一覧
- 新しい空きが1件もない回はメールを送りません
- 前回の結果は `state.json` に保存します

## セットアップ

1. **Gmailのアプリパスワードを発行**
   Googleアカウント →「セキュリティ」→ 2段階認証をオン →「アプリパスワード」で16桁のパスワードを作成します。

2. **GitHubにリポジトリを作成**
   このフォルダの中身（`.github` フォルダも含む）をすべてアップロードします。
   **Public リポジトリを推奨します。** 3サイトの確認には1回3〜4分かかります。Private リポジトリでは月2,000分の無料枠をほぼ使い切ってしまいますが、Public なら無制限に使えます。パスワード類は手順3の Secrets に入れるので、公開されません。

3. **Secretsを登録**
   リポジトリの Settings → Secrets and variables → Actions → New repository secret

   | 名前 | 値 |
   |---|---|
   | `GMAIL_USER` | 送信元のGmailアドレス |
   | `GMAIL_APP_PASSWORD` | 手順1のアプリパスワード |
   | `MAIL_TO` | 通知先アドレス（省略すると送信元と同じアドレス） |

4. **Actionsの書き込み権限を設定**
   Settings → Actions → General → Workflow permissions で「Read and write permissions」を選択します。

5. **手動で動作テスト**
   Actions タブ →「テニス空き確認」→ Run workflow。
   初回は、条件に合う空き枠がすべて「新しい空き」として届きます。
   ログにはサイトごとの「空き ◯件 / 条件一致 ◯件」が出ます。

## 設定を変えたいとき

`check_vacancy.py` の先頭にある設定を変更します。

- `EVENING_START_HOUR = 18`：平日に対象とする開始時刻です。`17` にすると17時開始の枠も対象になります。
- `KITA_FACILITIES`：北区で対象にする施設の一覧です（施設コード: 名前）。
- `ITA_EXCLUDE = "加賀"`：板橋区で除外する施設名です。
- 1つのサイトで取得に失敗しても、残りのサイトの通知は送られます。失敗したサイトは本文の「今回確認できなかったサイト」に表示されます。

## 注意

- GitHub の定期実行は、混雑時に数分〜数十分遅れることがあります。
- Public リポジトリでは、60日間更新がないと定期実行が自動で停止されることがあります。停止された場合は、Actions タブから再開してください。
- 予約サイトのページ構成が変わると動かなくなることがあります。
